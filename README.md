# TOP-calculator-project

## Notes

Crucial data for the development:

- Each operation have 3 data entries:

    1. The first number
    2. The operation (+, -, *, /)
    3. The second number

- The calculator must have the next functions:

    1. One function for each operation:
        - Addition (X + Y)
        - Subtraction (X - Y)
        - Multiplication (X * Y)
        - Division (X / Y)
    2. A function that equalize the operation
    3. A function that clears the calculator
